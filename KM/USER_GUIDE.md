# คู่มือใช้งาน FalCon2CP

ปรับปรุง: 2026-11-16 · อ้างอิงแอปใน `main` หลัง PR #85 (`a58764c`)

เว็บใช้งาน: https://spidersqdn.github.io/FalCon2CP/

คู่มือนี้อธิบายการใช้งานปัจจุบัน สำหรับผู้ใช้และบอตตอบคำถาม ชื่อปุ่มใช้ตามหน้าเว็บ
คำถามสั้นดู [FAQ](FAQ.md) และการแจ้งปัญหาดู [FEEDBACK](FEEDBACK.md)

## เริ่มต้นใช้งาน

1. เปิดเว็บ แล้วเลือกแผนที่ในหมวด **MAP**
2. ตั้ง **GS (KTS)** เป็นความเร็วที่ต้องการใช้คำนวณ
3. หากต้องการแก้ไขบนแผนที่ ให้ปุ่มข้างช่อง % เป็นสถานะ **🔓**
4. เลือก **เส้นทางหลัก** และ **On MAP** เพื่อแตะเพิ่มจุด
5. เมื่อต้องการเริ่มเส้นทางใหม่ ใช้ **CLEAR** หลังเก็บข้อมูลเดิมที่ต้องการแล้ว

เมื่อเริ่มจากเส้นทางว่าง ให้กำหนดจุด PZ และ LZ ก่อน การเพิ่มจุดถัดไปจะแทรกก่อน LZ
จุดระหว่างต้นทางและปลายทางจะเป็น CP โดยอัตโนมัติ สามารถลากจุดหรือแก้ชนิดจากป้ายจุดได้
แอปอาจมีเส้นทางตัวอย่างเมื่อเปิดครั้งแรก

## เพิ่มจุดจากแผนที่ พิกัด หรือการค้นหา

- **On MAP**: แตะแผนที่เพื่อเพิ่มจุดในเส้นทางที่กำลังเลือกอยู่
- **LAT/LONG**: กรอกละติจูดและลองจิจูด แล้วกด **Add ROUTE**
  ตัวอย่าง DDM: ละติจูด `16 07.01` และลองจิจูด `103 46.45`
- **ค้นหาสถานที่**: พิมพ์ ICAO เช่น `VTBS` หรือชื่อสถานที่ เลือกผลลัพธ์ แล้วกด **Add ROUTE** ในหน้าข้อมูล
- **Layers > AIRPORTS**: แตะสัญลักษณ์สนามบิน แล้วกด **Add ROUTE** ในหน้าข้อมูล

**Add ROUTE หมายถึงเพิ่มจุด** ไม่ใช่สร้างเส้นทางสำรอง ขณะล็อกแผนที่ การเพิ่มจุดจากการแตะแผนที่และหน้าข้อมูลถูกปิดไว้
พิกัด MGRS แสดงในหน้าข้อมูล/ตัวแก้ไขป้าย ช่อง LAT/LONG ใช้พิกัดละติจูดและลองจิจูด

## เส้นทางหลักและเส้นทางสำรอง

1. สร้างเส้นทางหลักให้มี PZ และ LZ อย่างน้อยสองจุด
2. กด **เส้นทางสำรอง** แอปจะสร้างเส้นทางสำรองโดยใช้ PZ/LZ ร่วมกับเส้นทางหลัก
3. เพิ่ม CP ของเส้นทางสำรอง แล้วใช้ปุ่ม **เส้นทางหลัก/เส้นทางสำรอง** เพื่อเลือกเส้นทางที่จะแก้ไข

- การแก้ชื่อหรือพิกัด PZ/LZ จะใช้ร่วมกันทั้งสองเส้นทาง
- ปุ่มสลับหลัก/สำรองเปลี่ยนบทบาทของสองเส้นทาง
- **BACK TRACK** กลับทิศเส้นทาง ต่างจากการสลับบทบาทหลัก/สำรอง
- ปุ่มลบเส้นทางสำรองลบเฉพาะเส้นทางสำรอง ส่วน **CLEAR** ลบทั้งสองเส้นทาง

## รูปแบบแผนที่และ Layers

- **NAVIGATION**: จุดแบบวงแหวน พร้อม LEG และ DOG LEG
- **แผนที่แผนสมบูรณ์**: PZ สีชมพู, CP สีเขียว, LZ สีเหลือง พร้อมตาราง TOTAL/ACTUAL/REMAIN

เปิดปุ่ม **Layers มุมขวาบนแผนที่** เพื่อเลือก:

| ตัวเลือก | สิ่งที่แสดง |
|---|---|
| AIRPORTS · สนามบิน | สนามบินจาก AP.txt และสนามบิน ทบ.; ไม่รวมค่ายทหารหรือหน่วยบิน |
| SHOW เส้นทางหลัก / สำรอง | เส้นทางที่เลือกแสดง |
| SHOW W.Pt หรือ SHOW PZ CPs LZ | ป้ายจุดและตารางตามรูปแบบ |
| SHOW DOG LEGs | กล่องข้อมูลแต่ละขาบิน |
| SHOW LEG | ข้อความ LEG ในรูปแบบ NAVIGATION |
| SHOW คำแสดงหลัก/สำรองในตาราง | คำแสดงบทบาทในรูปแบบแผนที่แผนสมบูรณ์ |

SHOW จำค่าแยกตามรูปแบบแผนที่ จึงอาจเห็นตัวเลือกต่างกันเมื่อสลับรูปแบบ
AIRPORTS จำค่าแยกจาก SHOW และยังเปิดได้แม้ซ่อนเส้นทาง เมนูยาวเลื่อนภายในได้
ข้อมูลสนามบินที่มีอาจแสดงชื่อ พิกัด ความสูง และความถี่; บางรายการไม่มีข้อมูลครบทุกช่อง

## เลื่อนกล่องและแก้ข้อมูล

1. ปลดล็อกให้เป็น **🔓**
2. ลากสัญลักษณ์จุดเพื่อเปลี่ยนพิกัด หรือลากป้าย/กล่องเพื่อจัดตำแหน่งบนแผนที่
3. แตะป้ายจุดเพื่อแก้ข้อความ ชนิดจุด เลข CP ขนาด หรือข้อมูลตาราง
4. แตะ DOG LEG เพื่อแก้ HDG/CRS, NM, เวลา, ALT และรูปแบบกล่อง แล้วกดบันทึก

ช่องค่าที่เว้นว่างในตัวแก้ไขกล่องใช้ค่าคำนวณอัตโนมัติ เวลาและความสูงอัตโนมัติขึ้นกับข้อมูลที่มี
ALT อัตโนมัติใช้ความสูงภูมิประเทศสูงสุดตามขาบิน ปัดขึ้นหลักร้อยฟุตแล้วเพิ่ม 500 ฟุต
หากข้อมูลภูมิประเทศยังไม่โหลด ALT อาจยังไม่ปรากฏ

**UNDO** ใช้ย้อนการแก้ไขจุดของเส้นทางที่กำลังทำ ไม่ใช่การย้อนทุกการตั้งค่า
**CLEAR** ล้างทั้งสองเส้นทางและประวัติ UNDO จึงไม่ควรใช้ UNDO เป็นวิธีกู้คืนหลัง CLEAR

## มุมมองกระดาษและปุ่มล็อก

ช่อง **มุมมองกระดาษ** อยู่บนสุดของ sidebar ใต้ช่องค้นหา

- เปิดมุมมองกระดาษเพื่อจัดป้าย/กล่องเทียบกับหน้ากระดาษ
- ปรับช่อง %, slider หรือปุ่ม −/+ ได้ในช่วง **10–400%**
- บนมือถือ กาง/หุบสองนิ้ว **บนแผนที่** เพื่อเปลี่ยน % ค่าจะเปลี่ยนตามนิ้วและจำไว้เมื่อปล่อย
- ในโหมดแผนที่ปกติ การกางนิ้วเปลี่ยนระดับซูมแผนที่ ไม่ใช่ % มุมมองกระดาษ
- เมนูไม่ซูมเมื่อกางนิ้วหรือแตะซ้ำ; ปุ่ม Layers คงขนาดเดิมขณะปรับ %

| ค่า | ผล |
|---|---|
| มาตราส่วน 1: ใน Export Map | มาตราส่วนแผนที่ที่จะพิมพ์ |
| Scale factor (%) ใน Export Map | เปลี่ยนมาตราส่วนที่จะพิมพ์จากค่าฐาน |
| % มุมมองกระดาษ | ย่อ/ขยายการแสดงผลบนจอ ไม่เปลี่ยนมาตราส่วนพิมพ์ |

กดปุ่ม **🔓/🔒 ข้างช่อง %** เพื่อสลับสถานะ:

- **🔒**: เลื่อนและซูมแผนที่ได้ แต่ลากจุด ป้าย กล่อง และตัวจับกรอบกระดาษไม่ได้; ไม่เปิดตัวแก้ไขจากแผนที่
- **🔓**: กลับมาแก้ไขและลากสิ่งเหล่านั้นได้

แอปจำสถานะล็อกไว้เมื่อเปิดใหม่ ล็อกนี้ใช้กับการแก้ไขบนแผนที่ ไม่ใช่การปิดทุกช่องตั้งค่าใน sidebar
บนมือถือ เมนูอยู่ล่างในแนวตั้งและอยู่ด้านข้างในแนวนอน ใช้ปุ่มลูกศรเพื่อเปลี่ยนการแสดงแผงเมนู

## แผนที่ออนไลน์และ offline

- ใน MAP มี JOG 1:250,000, TPC 1:500,000, OpenStreetMap และภาพดาวเทียม
- **เก็บแผนที่ที่เปิดดูไว้ใช้ offline** เก็บส่วนที่เคยเปิดดู ไม่ใช่ดาวน์โหลดทั้งประเทศ
- **IMPORT MAP** ใช้เปิดไฟล์ `.pmtiles` จากเครื่อง; การเลือกแผนที่อื่นไม่ใช่การนำเข้าเส้นทาง
- Safari เก็บไฟล์แผนที่ไว้ในเครื่องหนึ่งชุด หากบันทึกไม่สำเร็จต้องตรวจพื้นที่ว่างตามข้อความที่แอปแจ้ง
- Chrome/Edge ที่รองรับการอ่านไฟล์โดยตรงอาจขออนุญาตอ่านไฟล์อีกครั้งหลังเปิด browser ใหม่
- ข้อมูลสนามบิน/สถานที่ที่โหลดไว้มีสำเนาในเครื่อง แต่การค้นหาออนไลน์เพิ่มเติมต้องใช้เน็ต
- แผนที่ 1:50,000 ใช้ไฟล์ในเครื่อง; ไม่มีตัวเลือกออนไลน์ 1:50,000 ของโครงการนี้

การทำ/อัปเดตไฟล์แผนที่ดู [ONLINE](ONLINE.md)

## IMPORT และ EXPORT เส้นทาง

- **IMPORT** รองรับ CSV, KML, KMZ และ GPX เพื่อโหลดจุดเส้นทาง
- **EXPORT** ส่งออกเส้นทางหลักและสำรองเป็นไฟล์ที่เลือก
- การ IMPORT ปัจจุบันโหลดจุดเข้าเส้นทางหลักและล้างเส้นทางสำรองเดิม ควรเก็บข้อมูลเดิมก่อนนำเข้า
- ไฟล์ EXPORT ใช้ส่งต่อข้อมูลเส้นทาง ไม่ใช่สำเนาสถานะแอปครบชุด: ไม่เก็บตำแหน่งกล่องและทุกค่าหน้าจอ
- การนำไฟล์ที่มีทั้งหลัก/สำรองกลับเข้าแอปไม่ได้รับประกันว่าจะแยกสองเส้นทางหรือรูปแบบเดิมได้ครบ

เส้นทางและค่าที่จำไว้เก็บใน browser ของเครื่องนั้น ไม่มีการซิงก์เส้นทางอัตโนมัติข้ามเครื่อง

## PDF, Print และ SLIDE

1. ใน **Export Map** เลือกมาตราส่วน, Scale factor, A4/A3 และแนวกระดาษ
2. เปิดมุมมองกระดาษหรือแสดงกรอบเพื่อจัดตำแหน่งแผ่น; ปลดล็อกก่อนลากตัวจับเลขแผ่น
3. กด **Export PDF** หรือ **Print** เพื่อตรวจตัวอย่าง แล้วเลือกบันทึกหรือพิมพ์
4. เมื่อต้องการขนาดพิมพ์จริง ตั้งระบบพิมพ์เป็น **100% / Actual size**

**SLIDE** สร้าง Mission Overview 16:9 เป็น PNG สำหรับนำไปใช้ในสไลด์
AIRPORTS และ SHOW ที่เลือกมีผลต่อการแสดงแผนที่ส่งออก; แผนที่ใน SLIDE ใช้รูปแบบแผนที่แผนสมบูรณ์
SHOW ของรูปแบบนั้นอาจต่างจาก NAVIGATION ที่กำลังดูอยู่
