# แนวทางรับ feedback — FalCon2CP

ปรับปรุง: 2026-11-16

เอกสารนี้เป็นขั้นตอนและแม่แบบสำหรับบอตหรือผู้ดูแล ยังไม่ได้เชื่อมช่องทางรับข้อความหรือสร้างรายการติดตามอัตโนมัติ
ผู้รับเรื่องต้องบอกให้ชัดว่าเป็น **แบบร่าง**, **รวบรวมข้อมูลแล้ว** หรือ **ส่งเข้าระบบแล้ว**
ใช้สถานะส่งเข้าระบบแล้วเฉพาะเมื่อระบบปลายทางตอบรับจริง พร้อมเลขอ้างอิงหรือลิงก์ที่ตรวจสอบได้

## ประเภทเรื่อง

| ประเภท | ข้อมูลที่ควรถาม |
|---|---|
| ปัญหาการใช้งาน | ผู้ใช้ต้องการทำอะไร ติดที่ขั้นตอนไหน; ตอบจากคู่มือก่อน |
| แจ้งบั๊ก | ขั้นตอน ผลที่คาดหวัง ผลที่เกิดจริง และอุปกรณ์/browser |
| เสนอปรับปรุง | ปัญหาที่อยากแก้ วิธีที่ต้องการ และประโยชน์ต่อการใช้งาน |
| แก้ข้อมูลสนามบิน/สถานที่ | ชื่อหรือ ICAO รายการที่ผิด ค่าที่ควรเป็น และแหล่งอ้างอิงถ้ามี |
| แก้คู่มือ | ชื่อไฟล์/หัวข้อ ข้อความที่ไม่ตรง และคำแนะนำ |

## วิธีรับเรื่องในบทสนทนา

1. สรุปสิ่งที่ผู้ใช้พบหรือเสนอเป็นหนึ่งประโยค
2. ถามเฉพาะข้อมูลที่ยังขาดและจำเป็น ไม่ให้กรอกทุกช่องหากเป็นข้อเสนอทั่วไป
3. สำหรับบั๊กบนแผนที่ ถามสถานะ 🔓/🔒, รูปแบบแผนที่, มุมมองกระดาษ/% หรือ offline เท่าที่เกี่ยวข้อง
4. แยกข้อมูลที่ผู้ใช้รายงานออกจากผลที่ผู้ดูแลทดสอบเอง อย่าเรียกว่าบั๊กยืนยันแล้วหากยังไม่ทำซ้ำ
5. เสนอวิธีใช้งานตามคู่มือถ้ามี แล้วเก็บข้อเสนอเดิมไว้ แม้วิธีชั่วคราวจะช่วยแก้ปัญหาได้
6. สรุปเป็นแม่แบบด้านล่างเพื่อให้ผู้ใช้ตรวจ แล้วส่งต่อเมื่อมีช่องทางและคำขอให้ส่ง

## การส่งต่อให้ผู้ดูแล

- ปัญหาตัวแอปและคู่มือเป็นงานของ FalCon2CP
- ข้อมูลสนามบิน/สถานที่มาจาก CoWork ใน DataBase; ผู้ดูแลควรตรวจแหล่งข้อมูลก่อนแก้
- ปัญหาไฟล์แผนที่ออนไลน์ให้บันทึกชื่อแผนที่และพื้นที่/ระดับซูมที่เกิด โดยไม่ขอไฟล์แผนที่ทั้งชุดโดยอัตโนมัติ
- ที่เก็บ feedback และช่องทางบอตยังต้องเลือกภายหลัง ไม่สมมติว่ามี GitHub Issue, อีเมล หรือ LINE ที่ส่งสำเร็จแล้ว
- ไม่ขอรหัสผ่านหรือ token; ขอเส้นทาง/พิกัดจริงเท่าที่จำเป็นและใช้ตัวอย่างสมมติได้
- ไม่นำ feedback ของผู้ใช้ไป commit ลง repo สาธารณะโดยอัตโนมัติ

## ตัวอย่างรับเรื่องสั้น

ผู้ใช้: “บน iPad ลากกล่องไม่ได้”

บอต: “ตรวจปุ่มข้าง % ว่าเป็น 🔒 หรือไม่ครับ ถ้าใช่ให้ปลดล็อกก่อน หากยังลากไม่ได้ ขอทราบว่าใช้ Safari หรือไอคอนแอป และเป็นรูปแบบแผนที่ใดครับ”

ถ้ายังแก้ไม่ได้ ให้สรุปอาการและคำตอบที่ได้เป็นแบบร่าง ห้ามตอบว่า “ส่งให้นักพัฒนาแล้ว” จนกว่าจะส่งจริง
