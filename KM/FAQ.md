# คำถามที่พบบ่อย — FalCon2CP

ปรับปรุง: 2026-11-28 · ใช้ร่วมกับ [คู่มือใช้งาน](USER_GUIDE.md)

## ทำไมไม่เห็นแผนที่ JOG 1:250,000 หรือ TPC 1:500,000?

แอปเปิดใช้งานเริ่มต้นด้วย OpenStreetMap หากต้องการใช้แผนที่ JOG / TPC ให้กด **🔑 LOGIN** ในหมวด **MAP** แล้วใส่รหัสผ่าน
ระบบจะถามทุกครั้งที่เปิดแอปใหม่ โดยหลังเข้าสู่ระบบครั้งแรกสามารถใช้ Face ID / ลายนิ้วมือได้

## ทำไมลากจุด ป้าย หรือกล่องบนแผนที่ไม่ได้?

1. ตรวจปุ่มข้างช่อง % มุมมองกระดาษ ถ้าเป็น **🔒** ให้กดปลดล็อกเป็น **🔓**
2. หากต้องการ **ลากสัญลักษณ์จุด** (PZ/CP/LZ) ต้องเลือกโหมด **On MAP** ด้วย (โหมด **LAT/LONG** ล็อกการลากจุดบนแผนที่เพื่อกันเผลอขยับ)

หากยังไม่ได้ ให้แจ้งรูปแบบแผนที่ อุปกรณ์ และขั้นตอนตาม [FEEDBACK](FEEDBACK.md)

## ย้ายจุดด้วย LAT/LONG หรือ Radial/DME ทำอย่างไร?

แตะป้ายจุดบนแผนที่ (ขณะปลดล็อก **🔓**) หรือแตะรายการจุดใน sidebar
สามารถแก้ **LAT/LONG** ได้โดยตรง หรือเลือกสนามบินอ้างอิง ใส่ **RADIAL°** และ **DME NM** แล้วกด **SET**

## สนามบินเปิดตรงไหน?

เปิด **Layers มุมขวาบน > AIRPORTS · สนามบิน** แล้วแตะสัญลักษณ์เพื่อดูข้อมูล
หากยังไม่มีข้อมูล ให้ต่อเน็ตแล้วปิด–เปิด AIRPORTS อีกครั้ง ข้อมูลที่เคยโหลดไว้ใช้ซ้ำแบบ offline ได้

## Add ROUTE สร้างเส้นทางสำรองหรือไม่?

ไม่ใช่ ปุ่มนี้เพิ่มจุดลงในเส้นทางที่เลือกอยู่
สร้างเส้นทางหลักให้มี PZ/LZ แล้วกด **เส้นทางสำรอง** เพื่อเริ่มเส้นทางสำรอง

## ทำไมเพิ่มจุดแล้ว LZ ไม่ย้ายไปที่จุดใหม่?

เมื่อมี LZ อยู่ท้ายเส้นทาง การเพิ่มจุดจะแทรก CP ก่อน LZ เพื่อรักษาปลายทางเดิม
หากต้องการเปลี่ยนปลายทาง ให้ปลดล็อกและเลือก **On MAP** เพื่อลากจุด LZ หรือปรับชนิดจุดจากตัวแก้ไขป้าย

## SHOW หายไปไหน และทำไมสลับรูปแบบแล้วค่าเปลี่ยน?

SHOW อยู่ใน **Layers** และจำค่าแยกสำหรับ NAVIGATION กับแผนที่แผนสมบูรณ์
ให้เลือกรูปแบบก่อน แล้วตั้ง SHOW ในรูปแบบนั้น

## ซ่อนเส้นทางแล้วทำไมยังเห็นสนามบิน?

AIRPORTS เป็นเลเยอร์อิสระจาก SHOW เส้นทาง หากต้องการซ่อนด้วย ให้ปิด AIRPORTS

## ทำไมค่า % ไม่เปลี่ยนเมื่อกางนิ้ว?

ตรวจว่าเปิด **📄 มุมมองกระดาษ** อยู่ แล้วกาง/หุบสองนิ้วบนพื้นที่แผนที่ ค่า % อยู่ในช่วง 10–400% (อุปกรณ์สัมผัสมีค่าต่ำสุดอัตโนมัติ)
การกางนิ้วบนเมนูไม่ซูมเมนู ส่วนโหมดแผนที่ปกติจะเปลี่ยนระดับซูมแผนที่แทนค่า %

## ปรับ % มุมมองกระดาษแล้วมาตราส่วนพิมพ์เปลี่ยนหรือไม่?

ไม่เปลี่ยน % มุมมองกระดาษใช้ปรับการแสดงผลบนจอ
ค่าที่มีผลต่อมาตราส่วนพิมพ์คือ **มาตราส่วน 1:** และ **Scale factor (%)** ใน Export Map

## ปุ่มพิมพ์แผนที่อยู่ตรงไหน และใส่สัญลักษณ์ทิศเหนืออย่างไร?

ในหมวด **Export Map** กด **Export PDF** เพื่อเปิดหน้าต่างตัวอย่างก่อน
ในหน้าต่างตัวอย่างสามารถคลิกบนแผ่นเพื่อวาง/ย้าย **สัญลักษณ์ทิศเหนือ** (หรือกด **ใส่ทุกแผ่น**) แล้วเลือก **บันทึก PDF** หรือ **พิมพ์**
หากต้องการเอียงแผ่นตามแนวเส้นทางให้กด **ตามแนวเส้นทางบิน** ก่อนกด Export PDF

## DOC PLAN กับ SLIDE ต่างกันอย่างไร?

- **DOC PLAN** สร้างดราฟแผนสมบูรณ์ 2 หน้า A4 (หน้า 1 แผนที่ตามมุมมองกระดาษและรูปแบบปัจจุบัน, หน้า 2 ตารางเส้นทาง + ตารางพิกัด DDM/MGRS + NOTE ความถี่) ส่งออกได้ทั้ง **Word (.docx)**, **PDF** และ **PNG** เลือกเส้นทางหลักหรือสำรองได้
- **SLIDE** สร้างภาพ 16:9 Mission Overview เป็น PNG โดยใช้แผนที่รูปแบบแผนสมบูรณ์และค่าตามเส้นทางหลัก

## Offline ใช้แผนที่และ ALT ได้ทุกพื้นที่หรือไม่?

- แผนที่ออนไลน์ใช้ offline ได้เฉพาะพื้นที่ที่เคยเปิดดูไว้ (เมื่อเปิด **เก็บแผนที่ที่เปิดดูไว้ใช้ offline**)
- **IMPORT MAP** อ่านจากไฟล์ `.pmtiles` ที่มีในเครื่อง
- หากต้องการให้ **ALT** และ **Elevation Profile** ทำงานตอนไม่มีเน็ต ให้กด **⛰ โหลด Elevation** ในหมวด MAP (เลือกปกติ ~190MB หรือละเอียด ~750MB) ขณะต่อ Wi-Fi ไว้ล่วงหน้า

## ทำไม ALT ไม่แสดงหรือยังคำนวณไม่เสร็จ?

ALT อัตโนมัติต้องใช้ข้อมูลภูมิประเทศตามขาบิน ตรวจการเชื่อมต่อหรือโหลด Elevation เก็บไว้ก่อน
หากต้องกำหนดเอง ให้ปลดล็อกแล้วแตะ DOG LEG เพื่อแก้ ALT อย่าถือว่าช่องว่างหมายถึงความสูงศูนย์

## EXPORT เก็บตำแหน่งกล่องทั้งหมดหรือไม่?

ไม่ครบ ไฟล์เส้นทางไม่ใช่สำเนาสถานะแอปทั้งหมด จึงไม่รับประกันตำแหน่งกล่องหรือการแยกหลัก/สำรองเมื่อ IMPORT กลับ

## เปลี่ยนเครื่องหรือ browser แล้วเส้นทางจะตามมาหรือไม่?

ไม่มีการซิงก์อัตโนมัติ เส้นทางและแผนที่ในเครื่องเก็บแยกตาม browser/เครื่อง
ใช้ EXPORT เพื่อส่งต่อข้อมูลเส้นทาง แล้วตรวจผลหลัง IMPORT บนเครื่องปลายทาง

## กด CLEAR แล้วกด UNDO กู้คืนได้ไหม? และมี REDO ไหม?

**CLEAR** ลบทั้งสองเส้นทางและล้างประวัติ **UNDO / REDO** จึงใช้ UNDO กู้คืนหลัง CLEAR ไม่ได้
สำหรับการแก้ไขจุดปกติ ใช้ **UNDO** (`Ctrl+Z`) และ **REDO** (`Ctrl+Y` / `Ctrl+Shift+Z`) ในหมวด **FUNCTION**

## อัปเดตเว็บแล้วทำไมยังเห็นหน้าเดิม?

เชื่อมต่อเน็ตแล้วโหลดหน้าเว็บใหม่ หากมีแถบ **มีเวอร์ชันใหม่ · แตะเพื่ออัปเดต ⟳** ให้แตะแถบนั้น
หากยังพบปัญหา ให้แจ้ง URL ที่เปิด วิธีเปิดผ่าน browser/ไอคอนแอป และอุปกรณ์; ไม่แนะนำให้ล้างข้อมูลเว็บทันที

## แจ้งปัญหาหรือเสนอฟีเจอร์ได้อย่างไร?

ส่งอาการหรือข้อเสนอพร้อมข้อมูลเท่าที่ทราบตาม [FEEDBACK](FEEDBACK.md)
เอกสารชุดนี้ยังไม่ได้เชื่อมบอตหรือระบบบันทึก feedback อัตโนมัติ การส่งสำเร็จต้องมีผลยืนยันจากระบบรับเรื่องจริง
