# คู่มือใช้งาน FalCon2CP

ปรับปรุง: 2026-11-28 · อ้างอิงแอปใน `main` หลัง PR #115 (`81403a5`)

เว็บใช้งาน: https://spidersqdn.github.io/FalCon2CP/

คู่มือนี้อธิบายการใช้งานปัจจุบัน สำหรับผู้ใช้และบอตตอบคำถาม ชื่อปุ่มใช้ตามหน้าเว็บ
คำถามสั้นดู [FAQ](FAQ.md) และการแจ้งปัญหาดู [FEEDBACK](FEEDBACK.md)

## เริ่มต้นใช้งาน

1. เปิดเว็บ แอปเริ่มด้วยแผนที่ OpenStreetMap และเปิด **มุมมองกระดาษ** ให้อัตโนมัติ
2. หากต้องการใช้แผนที่ **JOG 1:250,000** หรือ **TPC 1:500,000** กด **🔑 LOGIN** ในหมวด **MAP** แล้วใส่รหัสผ่าน (ครั้งถัดไปรองรับ Face ID / ลายนิ้วมือ)
3. ตั้ง **GS (KTS)** เป็นความเร็วที่ต้องการใช้คำนวณ
4. ตรวจให้ปุ่มข้างช่อง % เป็น **🔓** และเลือก **เส้นทางหลัก** + **On MAP** เพื่อแตะเพิ่มจุด
5. เมื่อต้องการเริ่มเส้นทางใหม่ ใช้ **CLEAR** หลังเก็บข้อมูลเดิมที่ต้องการแล้ว

เมื่อเริ่มจากเส้นทางว่าง ให้กำหนดจุด PZ และ LZ ก่อน การเพิ่มจุดถัดไปจะแทรกก่อน LZ
จุดระหว่างต้นทางและปลายทางจะเป็น CP โดยอัตโนมัติ แอปอาจมีเส้นทางตัวอย่างเมื่อเปิดครั้งแรก

## เพิ่มจุดและแก้ไขพิกัด (On MAP / LAT/LONG / Radial/DME)

- **On MAP**: แตะแผนที่เพื่อเพิ่มจุด และลากสัญลักษณ์จุดบนแผนที่เพื่อย้ายพิกัดได้
- **LAT/LONG**: กรอกละติจูดและลองจิจูด (เช่น `16 07.01` / `103 46.45`) แล้วกด **Add ROUTE** (ขณะอยู่ในโหมด LAT/LONG สัญลักษณ์จุดบนแผนที่จะถูกล็อกไม่ให้เผลอลากย้าย)
- **ค้นหาสถานที่**: พิมพ์ ICAO เช่น `VTBS` หรือชื่อสถานที่ เลือกผลลัพธ์ แล้วกด **Add ROUTE** ในหน้าข้อมูล
- **Layers > AIRPORTS**: แตะสัญลักษณ์สนามบิน แล้วกด **Add ROUTE** ในหน้าข้อมูล
- **แก้พิกัดและ Radial/DME ของจุดเดิม**: แตะป้ายจุดบนแผนที่ หรือแตะรายการจุดใน sidebar เพื่อแก้ **LAT/LONG** โดยตรง หรือเลือกสนามบินอ้างอิงแล้วใส่ **RADIAL°** และ **DME NM** จากนั้นกด **SET**

**Add ROUTE หมายถึงเพิ่มจุด** ไม่ใช่สร้างเส้นทางสำรอง ขณะล็อกแผนที่ (**🔒**) การเพิ่มจุดจากการแตะแผนที่และหน้าข้อมูลจะถูกปิดไว้ พิกัด MGRS แสดงในหน้าข้อมูลและตัวแก้ไขป้าย

## เส้นทางหลักและเส้นทางสำรอง

1. สร้างเส้นทางหลักให้มี PZ และ LZ อย่างน้อยสองจุด
2. กด **เส้นทางสำรอง** แอปจะสร้างเส้นทางสำรองโดยใช้ PZ/LZ ร่วมกับเส้นทางหลัก
3. เพิ่ม CP ของเส้นทางสำรอง แล้วใช้ปุ่ม **เส้นทางหลัก / เส้นทางสำรอง** เพื่อเลือกเส้นทางที่จะแก้ไข

- การแก้ชื่อหรือพิกัด PZ/LZ จะใช้ร่วมกันทั้งสองเส้นทาง
- ปุ่ม **⇄** สลับบทบาทเส้นทางหลัก/สำรอง ส่วน **✕** ลบเฉพาะเส้นทางสำรอง
- **BACK TRACK** กลับทิศเส้นทางทั้งหลักและสำรองโดยคงเลข CP เดิม และรีเซ็ตการกลับด้าน DOG LEG ให้หันตามแนว PZ→LZ ใหม่
- **CLEAR** ลบทั้งสองเส้นทางและล้างประวัติ UNDO/REDO

## รูปแบบแผนที่และ Layers

- **NAVIGATION**: จุดแบบวงแหวน พร้อม LEG และ DOG LEG
- **แผนที่แผนสมบูรณ์**: PZ สีชมพู, CP สีเขียว, LZ สีเหลือง พร้อมตาราง TOTAL/ACTUAL/REMAIN

เปิดปุ่ม **Layers มุมขวาบนแผนที่** เพื่อเลือก:

| ตัวเลือก | สิ่งที่แสดง |
|---|---|
| AIRPORTS · สนามบิน | สนามบินจาก AP.txt และสนามบิน ทบ.; ไม่รวมค่ายทหารหรือหน่วยบิน |
| SHOW เส้นทางหลัก / สำรอง | เส้นทางที่เลือกแสดง |
| SHOW W.Pt หรือ SHOW PZ CPs LZ | ป้ายจุดและตารางตามรูปแบบ |
| SHOW DOG LEGs | กล่องข้อมูลแต่ละขาบิน |
| SHOW LEG | ข้อความ LEG ในรูปแบบ NAVIGATION |
| SHOW คำแสดง หลัก/สำรอง ในตาราง | คำแสดงบทบาทในรูปแบบแผนที่แผนสมบูรณ์ |

SHOW จำค่าแยกตามรูปแบบแผนที่ ส่วน AIRPORTS จำค่าแยกจาก SHOW และเปิดได้แม้ซ่อนเส้นทาง
ข้อมูลสนามบินแสดงชื่อ พิกัด ความสูง และความถี่เท่าที่มีในฐานข้อมูล

## เลื่อนกล่อง แก้ข้อมูล และ UNDO/REDO

1. ปลดล็อกให้เป็น **🔓** (หากจะลากสัญลักษณ์จุด ต้องอยู่ในโหมด **On MAP** ด้วย)
2. ลากป้าย กล่อง LEG หรือ DOG LEG เพื่อจัดตำแหน่งบนแผนที่
3. แตะป้ายจุดเพื่อแก้ข้อความ ชนิดจุด เลข CP (`FLY OVER / FLY BY`) ขนาด พิกัด LAT/LONG, Radial/DME หรือข้อมูลตาราง
4. แตะ DOG LEG เพื่อแก้ HDG/CRS, NM, เวลา, ALT, รูปแบบกล่อง หรือติ๊ก **กลับด้าน DOG LEG 180°** แล้วกดบันทึก

- DOG LEG หันตัวเลขอ่านตั้งตรงตามแนว PZ→LZ อัตโนมัติ; ช่องค่าที่เว้นว่างจะใช้ค่าคำนวณอัตโนมัติ
- ALT อัตโนมัติใช้ความสูงภูมิประเทศสูงสุดตามขาบิน ปัดขึ้นหลักร้อยฟุตแล้วเพิ่ม 500 ฟุต
- ในหมวด **FUNCTION** มี **UNDO** (`Ctrl+Z`) และ **REDO** (`Ctrl+Y` / `Ctrl+Shift+Z`) สำหรับย้อน/ทำซ้ำการแก้ไขจุดของเส้นทางที่กำลังทำ (ไม่สามารถกู้คืนหลัง **CLEAR** ได้)

## มุมมองกระดาษและปุ่มล็อก

ช่อง **📄 มุมมองกระดาษ** อยู่บนสุดของ sidebar ใต้ช่องค้นหา (เปิดเป็นค่าเริ่มต้นเมื่อเข้าแอป)

- ปรับช่อง %, slider หรือปุ่ม −/+ ได้ในช่วง **10–400%** (อุปกรณ์สัมผัสมีค่าต่ำสุดอัตโนมัติเพื่อไม่ให้หน่วยความจำเต็ม)
- บนมือถือ/แท็บเล็ต กาง/หุบสองนิ้ว **บนแผนที่** เพื่อเปลี่ยน % ค่าจะจำไว้เมื่อปล่อยนิ้ว
- ในโหมดแผนที่ปกติ (ปิดมุมมองกระดาษ) การกางนิ้วเปลี่ยนระดับซูมแผนที่ ไม่ใช่ % มุมมองกระดาษ
- เมนูไม่ซูมเมื่อกางนิ้วหรือแตะซ้ำ; ปุ่ม Layers คงขนาดเดิมขณะปรับ %

| ค่า | ผล |
|---|---|
| มาตราส่วน 1: ใน Export Map | มาตราส่วนแผนที่ที่จะพิมพ์ |
| Scale factor (%) ใน Export Map | เปลี่ยนมาตราส่วนที่จะพิมพ์จากค่าฐาน |
| % มุมมองกระดาษ | ย่อ/ขยายการแสดงผลบนจอ ไม่เปลี่ยนมาตราส่วนพิมพ์ |

กดปุ่ม **🔓/🔒 ข้างช่อง %** เพื่อสลับสถานะ (จำสถานะไว้เมื่อเปิดใหม่):

- **🔒**: เลื่อนและซูมแผนที่ได้ แต่ลากจุด ป้าย กล่อง และตัวจับกรอบกระดาษไม่ได้; ไม่เปิดตัวแก้ไขจากแผนที่
- **🔓**: กลับมาแก้ไขและลากสิ่งเหล่านั้นได้

## แผนที่ออนไลน์, LOGIN และ Offline

- แอปเปิดใช้งานได้ทันทีบน **OpenStreetMap** และ **ภาพดาวเทียม (Esri)**
- **🔑 LOGIN** (ในหมวด MAP): ใส่รหัสผ่านเพื่อปลดล็อก **JOG 1:250,000** และ **TPC 1:500,000** (ถามทุกครั้งที่เปิดแอปใหม่; หลังเข้าครั้งแรกจะบันทึก passkey ให้สแกน Face ID / ลายนิ้วมือได้)
- **เก็บแผนที่ที่เปิดดูไว้ใช้ offline**: เก็บเฉพาะพื้นที่ที่เคยเปิดดูไว้ในเครื่อง และจำสถานะสวิตช์ไว้เมื่อเปิดใหม่
- **⛰ โหลด Elevation**: ดาวน์โหลดข้อมูลความสูงภูมิประเทศทั้งพื้นที่แผนที่เก็บไว้ใช้ offline (เลือก **ปกติ ~190MB** หรือ **ละเอียด ~750MB** กด **⏹ หยุด** แล้วกดโหลดต่อภายหลังได้) เพื่อให้ ALT และ Elevation Profile ทำงานตอนไม่มีเน็ต
- **ล้าง cache**: ลบแผนที่และข้อมูล Elevation ที่เก็บไว้ในเครื่องทั้งหมด
- **📁 IMPORT MAP**: เปิดไฟล์ `.pmtiles` จากเครื่อง (เช่น 1:50,000, ONC, JNC, GNC) Chrome/Edge อ่านจากไฟล์เดิมโดยตรง ส่วน Safari เก็บสำเนาไว้ในเครื่องหนึ่งชุด
- การเปิดแผนที่ผ่านลิงก์ `?map=<url>` จากเว็บไซต์ภายนอกจะขึ้นข้อความยืนยันก่อนเปิด

การทำ/อัปเดตไฟล์แผนที่ดู [ONLINE](ONLINE.md)

## IMPORT, EXPORT, DOC PLAN และ SLIDE (หมวด FUNCTION)

- **IMPORT**: โหลดจุดจาก CSV, KML, KMZ หรือ GPX เข้าเส้นทางหลัก (ล้างเส้นทางสำรองเดิม)
- **EXPORT ▾**: ส่งออกเส้นทางหลักและสำรองเป็น KML, KMZ, GPX หรือ CSV (ไม่เก็บตำแหน่งกล่องและทุกค่าหน้าจอ)
- **DOC PLAN**: สร้างดราฟแผนสมบูรณ์ 2 หน้า A4 ส่งออกเป็น **Word (.docx)**, **PDF** หรือ **PNG** (บน iPhone/iPad เปิดหน้าต่างแชร์)
  - เลือกใช้ค่าจาก **เส้นทางหลัก** หรือ **เส้นทางสำรอง**, แก้ **หัวเรื่อง**, **FLIGHT ALT (ft)** และ **NOTE** (กด **เติม NOTE อัตโนมัติ** เพื่อดึงความถี่ PZ/LZ, `RADAR OSCAR CONTROL` หรือ `DIAMOND UHF 236.000` สำหรับจุดที่ไม่ใช่สนามบิน)
  - หน้า 1 แสดงแผนที่ตามมาตราส่วนมุมมองกระดาษและรูปแบบแผนที่ปัจจุบัน หน้า 2 แสดงตาราง CP/HDG/DISTANCE/TIME/ALT และตารางพิกัด (DDM/MGRS) + NOTE
- **SLIDE**: สร้างภาพ 16:9 Mission Overview เป็น PNG (แผนที่รูปแบบแผนสมบูรณ์ + ตารางข้อมูลตามเส้นทางหลัก)

เส้นทางและค่าที่จำไว้เก็บใน browser ของเครื่องนั้น ไม่ซิงก์ข้ามเครื่องอัตโนมัติ

## Export Map (PDF ขนาดจริง แบ่งแผ่น)

1. ใน **Export Map** เลือกมาตราส่วน, Scale factor, กระดาษ A4/A3 และแนวกระดาษ
2. กด **แสดง/ซ่อนกรอบ** เพื่อดูกรอบแผ่นบนแผนที่; ปลดล็อก (**🔓**) ก่อนลากเลขแผ่นสีแดง (**✥**) เลือก **เลื่อนแผ่นเดียว** หรือ **เลื่อนทั้งหมด**
3. กด **ตามแนวเส้นทางบิน** หากต้องการเอียงแผ่นกระดาษตามขาบินที่ยาวที่สุดของเส้นทางที่แสดงอยู่เพื่อประหยัดกระดาษ
4. กด **Export PDF** เพื่อเปิดหน้าต่างตัวอย่าง จากนั้นคลิกบนแต่ละแผ่นเพื่อวาง/ย้าย **สัญลักษณ์ทิศเหนือ** (คลิกซ้ำที่เดิมเพื่อลบ หรือใช้ **ใส่ทุกแผ่น / ลบทั้งหมด**) แล้วเลือก **บันทึก PDF** หรือ **พิมพ์**
5. ตอนพิมพ์ PDF ให้ตั้งสเกลเครื่องพิมพ์เป็น **100% / Actual size** (ห้าม Fit to page)
